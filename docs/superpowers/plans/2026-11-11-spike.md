# tgx Spike (WS relay + TDLib, Slint message list) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the two riskiest parts of tgx from spec §8: (1) a Rust local MTProto→WSS relay that TDLib can use on a blocked network, including media downloads; (2) Slint rendering a 10k-item variable-height message list smoothly.

**Architecture:** Cargo workspace. `crates/tgx-transport` is a real, kept library (handshake parsing, re-encryption, packet framing, WSS dialing, loopback listener) built TDD with network-independent tests. Two throwaway binaries under `spikes/` exercise it against real Telegram (`relay-tdlib`) and measure Slint (`slint-list`). Results go into a spike report that decides the MVP plan.

**Tech Stack:** Rust 1.93 stable (MSVC), tokio, tokio-tungstenite + rustls (webpki roots), `aes` + `ctr` + `sha2`, `rand`, `tdlib-rs` 1.4.0 (`download-tdlib`, TDLib 1.8.61), Slint 1.18.

**Spec:** `docs/specs/2026-11-09-tgx-client-design.md` (§5.3, §5.4, §7, §8, §8.1). Protocol reference: Flowseal/tg-ws-proxy @ `6690b78` (MIT) — `proxy/tg_ws_proxy.py`, `proxy/bridge.py`, `proxy/utils.py`, `proxy/pool.py`.

## Global Constraints

- Windows 10/11 x64, toolchain `stable-x86_64-pc-windows-msvc`.
- Listener binds `127.0.0.1` only, random free port (`:0`), random 16-byte per-run secret; TDLib gets it as `proxyTypeMtproto` with secret `"dd" + hex(secret)`.
- Forced routes never fall back; the relay never connects a DC directly — an unreachable DC is reported, the client connection is closed.
- Full TLS certificate validation (webpki roots); no `danger_*` / insecure verifiers.
- `api_id`/`api_hash` come from env vars `TGX_API_ID` / `TGX_API_HASH` at runtime; never committed. `.env`, TDLib dirs and `target/` are git-ignored.
- Logs (relay and spike) never contain message text, phone numbers, codes, passwords, or secrets (the proxy secret is printed only as "set", never its value).
- Attribution: `crates/tgx-transport/NOTICE` credits Flowseal/tg-ws-proxy (MIT) with its licence text.
- Crate versions: add with `cargo add` and commit the resolved `Cargo.lock`; do not hand-pick yanked/older majors.

## Review Focus

1. **Init split across TCP reads** (client sends 64-byte init in pieces) — relay must `read_exact`, not assume one read. → Task 4 test `init_arrives_in_fragments`.
2. **Transport packet split across reads / length header split** (abridged `0x7f` 4-byte header, intermediate 4-byte LE length) — splitter buffers and emits whole packets only. → Task 2 tests.
3. **Upstream WS closes mid-stream** — client TCP socket closes promptly, both copy tasks end, no leaked task. → Task 4 test `upstream_close_closes_client`.
4. **Junk on the port** (HTTP GET, TLS ClientHello `0x16`, random bytes) — rejected without dialing upstream; drained at most 64 KiB / 10 s. → Task 4 test `junk_is_rejected_without_dial`.
5. **Many parallel TDLib connections incl. media DCs** (`dc_idx < 0`) — handled concurrently; media maps to `kws{dc}-1` then `kws{dc}`. → Task 3 `media_domains_order`, Task 4 `parallel_clients_are_independent`.

**Interfaces:**
- Produces:
  ```rust
  pub const HANDSHAKE_LEN: usize = 64;
  #[derive(Clone, Copy, Debug, PartialEq, Eq)]
  pub enum ProtoTag { Abridged, Intermediate, PaddedIntermediate } // ef×4, ee×4, dd×4
  #[derive(Clone, Copy, Debug, PartialEq, Eq)]
  pub struct ClientInit { pub dc: u16, pub media: bool, pub test_dc: bool, pub proto: ProtoTag, prekey_iv: [u8; 48] }
  pub fn parse_client_init(init: &[u8; 64], secret: &[u8; 16]) -> Option<ClientInit>;
  pub fn generate_relay_init(proto: ProtoTag, dc_idx: i16) -> [u8; 64];
  pub struct CryptoCtx { /* clt_dec, clt_enc, tg_enc, tg_dec : Ctr128BE<Aes256> */ }
  impl CryptoCtx {
      pub fn new(client: &ClientInit, secret: &[u8; 16], relay_init: &[u8; 64]) -> Self;
      pub fn client_to_tg(&mut self, buf: &mut [u8]) -> Vec<u8>; // decrypts buf in place (→ plain), returns re-encrypted copy
      pub fn tg_to_client(&mut self, buf: &mut [u8]);            // in place: tg cipher → client cipher
  }
  ```
  `client_to_tg` returns the tg-side ciphertext and leaves the plaintext in `buf` because `PacketSplitter` (Task 2) needs both.

### Task 2: Transport packet splitter (`framing.rs`)

**Files:** Create `crates/tgx-transport/src/framing.rs`; tests inline.

**Interfaces:**
- Consumes: `ProtoTag` (Task 1).
- Produces:
  ```rust
  pub struct PacketSplitter { /* proto, cipher_buf, plain_buf, disabled */ }
  impl PacketSplitter {
      pub fn new(proto: ProtoTag) -> Self;
      pub fn split(&mut self, cipher: &[u8], plain: &[u8]) -> Vec<Vec<u8>>; // whole packets (cipher bytes) ready for one WS frame each
      pub fn flush(&mut self) -> Option<Vec<u8>>;                           // remaining bytes at EOF
  }
  ```

- [ ] **Step 1: Failing tests** (plain == cipher in tests is fine; the splitter decides only on `plain`):
  - `abridged_short_header`: `[0x02, 8 bytes]` → one packet of 9 bytes.
  - `abridged_long_header`: `[0x7F, 0x01,0x00,0x00, 4 bytes]` and `[0xFF, …]` (quick-ack bit) → one packet of 8 bytes each.
  - `intermediate_len_and_quickack_bit`: `[8,0,0,0, 8 bytes]` and `[8,0,0,0x80, 8 bytes]` → packets of 12.
  - `two_packets_in_one_chunk` → 2 parts in order.
  - `header_split_across_calls`: feed `[0x7F, 0x01]` then `[0x00, 0x00, 4 bytes]` → first call returns `[]`, second returns one 8-byte packet.
  - `zero_length_disables_splitting`: intermediate header `0` → returns all buffered bytes as one part and subsequent calls pass chunks through unchanged (upstream behaviour).
  - `flush_returns_tail`: incomplete packet then `flush()` → `Some(tail)`, then `None`.

### Task 4: Relay listener (`relay.rs`) + loopback tests

**Files:** Create `src/relay.rs`, `tests/loopback.rs`.

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
  ```rust
  #[derive(Clone, Debug)]
  pub enum RelayEvent { Connected(DcTarget), DcUnreachable { target: DcTarget, error: String }, BadHandshake }
  pub struct RelayHandle { pub addr: SocketAddr, pub events: mpsc::Receiver<RelayEvent>, /* secret, shutdown */ }
  impl RelayHandle {
      pub fn tdlib_secret(&self) -> String; // "dd" + 32 lowercase hex chars
      pub async fn shutdown(self);
  }
  pub async fn start_relay<D: Dialer>(dialer: D) -> io::Result<RelayHandle>; // binds 127.0.0.1:0, random secret
  pub async fn start_relay_with_secret<D: Dialer>(dialer: D, secret: [u8; 16]) -> io::Result<RelayHandle>; // tests
  ```
  Per connection: set `TCP_NODELAY`; `read_exact` 64 bytes with 10 s timeout; first byte `0x16` or `parse_client_init == None` → send `BadHandshake`, drain ≤ 64 KiB within 10 s, close, **no dial**. Otherwise dial up to 3 attempts (backoff 200 ms, 400 ms, ±20 % jitter); on failure send `DcUnreachable` and close. On success send `Connected`, send relay init as one binary frame, then two tasks: client→tg (`read` ≤ 64 KiB → `client_to_tg` → `splitter.split` → one binary frame per packet; on EOF send `flush()` then close WS) and tg→client (binary frames → `tg_to_client` → write; ignore ping/pong handled by tungstenite; close/err → shutdown client write). When either side ends, abort the other. Events channel bounded (64), `try_send` (drop if full — events are diagnostic).

- [ ] **Step 1: Failing tests** in `tests/loopback.rs`. Test fixtures: `FakeTelegram` = `TcpListener` on 127.0.0.1 accepting plain WS (`tokio_tungstenite::accept_hdr_async`, echo back subprotocol `binary`), reads the 64-byte relay init frame, derives standard-obfuscation keys (as in Task 1 test), records decrypted plaintext and replies with `"pong:" + plaintext` encrypted with its own stream. `LoopDialer { addr, dials: AtomicUsize }` implements `Dialer` by `client_async` over plain TCP (`MaybeTlsStream::Plain`). Client side uses the Task 1 test helper logic (copy the helper into `tests/common/mod.rs`).
  - `relays_payload_both_ways`: intermediate proto, dc 2; send packet `[len=8][8 bytes]` → FakeTelegram sees exact plaintext; client decrypts reply `pong:…`.
  - `init_arrives_in_fragments`: write the 64-byte init as 10+30+24 bytes with 20 ms gaps → same result.
  - `junk_is_rejected_without_dial`: send `b"GET / HTTP/1.1\r\n\r\n"` padded to 64 bytes → event `BadHandshake`, `dials == 0`, socket closed within 11 s (use `tokio::time::pause` + advance).
  - `unreachable_dc_reported_and_closed`: dialer returning `DialError::NoRoute` → event `DcUnreachable`, client sees EOF, `dials == 3`.
  - `upstream_close_closes_client`: FakeTelegram closes WS after first reply → client read returns EOF within 1 s.

  - `tdlib_secret_format`: matches `^dd[0-9a-f]{32}$`; listener `addr.ip()` is `127.0.0.1`.
