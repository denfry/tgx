tgx — лёгкий клиент Telegram для Windows со встроенным обходом блокировок.

Как запустить
1. Распакуйте архив в любую папку (например, Документы\tgx). Установка не нужна.
2. Запустите tgx.exe.
3. Windows может показать синее окно «Система Windows защитила ваш компьютер»:
   у tgx пока нет платной цифровой подписи. Нажмите «Подробнее», затем
   «Выполнить в любом случае». Это нужно сделать один раз.
4. Войдите: номер телефона, код из Telegram, облачный пароль, если он есть.

Прокси настраивать не нужно: tgx сам подключается через встроенный транспорт.
Внизу окна видно, через какой маршрут идёт соединение.

Данные хранятся только на этом компьютере, в папке %LOCALAPPDATA%\tgx.
Чтобы выйти из аккаунта на этом ПК, закройте tgx и удалите эту папку.

Исходный код и новые версии: https://github.com/denfry/tgx
tgx — неофициальный клиент, он не связан с Telegram.
